# Agente MEMO - Protocolo de Memoria y Conversaciones

## Regla de Ejecución
- **Lectura Obligatoria Inicial**: Antes de responder a nuevas tareas o al reanudar una sesión, lee `Memo/memo.md` para conocer el contexto de las conversaciones recientes entre el Usuario y Antigravity.
- **Ubicación del Archivo**: `f:/Onedrive/ANTIGRAVITY/ANTA_OBRA/Memo/memo.md`
- **Sincronización**: Mantén el archivo al día con las conversaciones literales. Para sincronizar automáticamente desde los logs de sesión se dispone del script `Memo/sync_memo.py`.
